# Design Guidelines & System Rules

## 1. Typography
- **Minimum Font Size**: `16px` (`text-base` / `text-[16px]`). No font size smaller than `16px` should be used anywhere in the design.

## 2. Elevation & Shadows
- **Box Shadow**: `none` (`shadow-none`). Absolutely no box shadows allowed on buttons, cards, headers, or containers.

## 3. Border Radius
- **Maximum Border Radius**: `8px` (`rounded-[8px]` / `rounded-md`). Do not exceed `8px` border radius on buttons, inputs, cards, or modals.

## 4. Header & Navigation Layout
- **Logo**: Use the project logo located at `/foxses_logo.png`.
- **Menu Items**: Clean text links with subtle chevron indicator for dropdowns (`text-[16px]`).
- **Color Scheme**: Minimal off-white/light header background (`#f8f8f7` / `#f9f9f8` or `#ffffff`), clean dark text (`#111111`), no bright orange or artificial gradients.
- **Action Buttons**:
  - **Login**: Plain text link (`text-[16px]`).
  - **Book a Demo / Secondary Action**: White background, thin border (`border-zinc-300`), max 8px border radius, no shadow.
  - **Get Started Free / Primary Action**: Solid dark background (`bg-black` or `bg-zinc-900`), white text, max 8px border radius, no shadow.
